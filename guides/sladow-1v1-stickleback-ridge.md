# Stickleback Ridge

A 1v1 build order by Sladow-Noob.

## Build

- **ACU:** Fac - 3 PGs - 4 Mex - 3 PGs - landfac - 3 PGs - landfac - 2 PGs - landfacs
- **Landfac:** 2 engis - tank - scout - 2 engis - tank - scout - engis
- **Engi 1:** Assist PGs then reclaim rocks behind base - assist ACU again
- **Engi 2:** Reclaim rocks between base / hydro - expand mexes and hydro
- **Engi 3:** Assist ACU
- **Engi 4:** Expand to other side

## Notes

- Not an optimal build order.
- Advice from Tagada: watch Espi's replays.
